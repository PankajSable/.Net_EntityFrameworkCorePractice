This repository contains **complete practice source code and handwritten notes** based on an **Entity Framework Core 8.0 tutorial**.  
It is designed as a **step-by-step beginner-friendly learning resource** for mastering database programming using **EF Core and LINQ**.

---

## 🔥 Topics Covered

- Introduction to Entity Framework Core
- EF Core setup & configuration
- Creating data models & entities
- CRUD operations (Create, Read, Update, Delete)
- LINQ to SQL queries
- Database migrations & schema updates
- Entity relationships  
  - One-to-One  
  - One-to-Many  
  - Many-to-Many
- Performance optimization techniques
- Best practices & common mistakes
- Real-world examples
